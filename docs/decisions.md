# 架构决策记录（ADR）

本文件记录对 `design.md` 原始方案的已批准调整（2026-08-07 评审确认，全部纳入实现）。

## ADR-001 翻译降级为"能力"而非独立阶段
- 英文原文 chunk 是唯一 source of truth；章节写作直接 英文 in / 中文 out。
- 独立翻译管线仅保留给需逐字保留的内容（注意事项块、参数表说明、错误信息）。
- 术语表（glossary）与风格指南注入写作 prompt；翻译质检项平移到写作输出。
- 影响：design.md 的 M4（翻译）不再是 M6 的前置阶段；glossary 构建保留。

## ADR-002 学习路径：侧边栏主干 + LLM 依赖边校正
- 官方侧边栏顺序作为学习路径主干与拓扑排序 tiebreaker（带优先级的拓扑排序）。
- LLM 依赖边只用于检测违例（"第3章用到第9章概念"）并局部重排。
- 依赖图不做纯 DAG 假设：Tarjan 求 SCC → 缩点图拓扑排序 → SCC 内按侧边栏序。
- 影响：M1 的 BFS 发现必须记录侧边栏顺序（sidebar_index），供 M2/M4 使用。

## ADR-003 范围界定步骤（scope bounding）
- 一个根 URL 可能覆盖多个产品线（如 elastic.co/guide）。发现阶段后自动识别产品边界
  （sitemap 路径首段聚类 + 侧边栏顶层结构），输出 scope 建议；
  支持配置收窄（include/exclude 前缀）或拆分为多卷。
- 影响：manifest.json 增加 `scope` 字段；M1 即落地机制。

## ADR-004 三级覆盖率指标
- L1 抓取覆盖率 = 解析成功页 / 发现页（M1 落地）。
- L2 概念覆盖率 = 大纲覆盖概念 / 图谱概念总数（M2/M4）。
- L3 内容覆盖率 = 被章节引用的 chunk / 总 chunk（M4，作为"无遗漏"的门禁指标）。

## ADR-005 Demo 校验加固（M3 落地，先行记录）
- 沙箱默认禁止出网；外部服务走本地替身（mock endpoint / fixture）；需真凭据的 demo
  标记 opt-in 独立通道，不计入通过率门禁。
- 断言独立于生成方：优先提取官方文档示例输出，否则独立验证器调用；
  退出码 0 + 空输出判失败。
- 自愈回归护栏：修复后必须仍包含目标 API/符号，否则拒绝修复、降级人工。

## ADR-006 评测基线与产物溯源元数据
- 3 个代表性站点冻结为本地快照作为 eval 基线（质量回归用）。
- 每个落盘产物记录 `(tool_version, prompt_version, model, 输入hash)`；LLM 步骤按输入 hash 缓存
  （LLM 步骤非幂等，目标是"可重跑 + 缓存"，而非 design.md 4.7 所说的"幂等"）。
- 增量更新不覆盖 locked（人工修改过）的章节，冲突上报。

## ADR-007 其他结构性决定
- 双引擎差异告警不对称：侧边栏有但未抓到 = 硬错误；sitemap 有但侧边栏无 = 软提示。
- `api-reference` 不做全局丢弃：per-adapter 策略 + 体量阈值，默认降级为"可检索附录"。
- 去重先用确定性方法（simhash/minhash），向量只做语义级重叠（M2）。
- 版本信息冒泡：chunk 带版本 tag；混版本 chunk 不合入同一 demo（M3）；手册封面标注文档版本。
- license 识别落入 manifest（页脚/链接扫描），不明确时在报告中标注风险。
- 架构图类图片在 M2+ 用 VLM 生成结构化描述喂入写作上下文；图片重新托管需记录来源。
- 抓取层实现：httpx 快路径 + 自研 JS 壳检测 + Playwright 升级（Crawl4AI 作为可选后端保留接口位，
  首期不引入其重依赖）。
